# Gallery

Every preset has a paired GPU/ray example generated by real PyMOL. The
[published gallery](https://github.com/th2ch-g/blender_style_in_pymol/tree/gallery)
shows all 16 representation choices and 8 materials. The root README embeds
the two overview images from this generated branch. The
[CI workflow](https://github.com/th2ch-g/blender_style_in_pymol/actions/workflows/ci.yml)
publishes these as the `pymol-gallery` artifact. Download the artifact from a
successful run, unzip it, and open `index.html` to compare the images.

The repository keeps the renderer and gallery specification. Downloaded
structures, generated images, HTML and measurement manifests are ignored.
CI publishes generated files to the separate `gallery` branch; no generated
data is committed to `main`. The branch also includes `index.html` for local
viewing and a Markdown table for GitHub's viewer.

## Regenerate

```sh
pixi install --locked
pixi run gallery --fetch
```

Open `.cache/gallery/index.html`. Images are 1200 × 900 with `quality=high`,
white background, an orthographic camera and identical protein views.
Atomic examples use PyMOL's tryptophan fragment. The other examples use
[crambin, PDB 1CRN](https://www.rcsb.org/structure/1CRN).
`--fetch` downloads that coordinate file only if it is missing.

For an existing local coordinate file:

```sh
pixi run gallery --structure molecule.cif
```

For headless ray-only images:

```sh
pixi run uv run --no-project --python .pixi/envs/default/bin/python python \
    scripts/render_gallery.py --fetch
```

Use `--only cartoon surface` to render specific cases, `--output` to choose an
output directory, and `--width`/`--height` to select resolution. `--keep-open`
leaves the Qt viewer and plugin dialog open for interactive inspection.

| Cases | Input | Material/representation |
| --- | --- | --- |
| cartoon, ribbon, cartoon-rounded, cartoon-cylinders | 1CRN | Studio material |
| spheres, ball-and-stick, sticks | Tryptophan fragment | Studio material |
| surface | 1CRN | Studio material |
| preset-1, preset-2, preset-3, preset-4 | 1CRN | Legacy polymer/atom combinations |
| density-surface, density-wire, density-iso-surface | Synthetic signed Gaussian field | Threshold 0.2 |
| oxdna-ribbon | Synthetic 36-nucleotide duplex | Oriented bases and backbone |
| studio, matte, glossy, flat, outline | 1CRN | Cartoon |
| ambient-occlusion, clay, transparent | 1CRN | Surface |

The generator validates dimensions and nonempty output for every image and
records hashes, timings and the PyMOL version in `manifest.json`. Outlines
are present in ray output only. The CPU/GPU lighting and transparency paths
can differ; both are shown explicitly.
